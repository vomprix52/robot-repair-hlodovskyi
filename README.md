### 21.09.2026 — Юніт 1: персонаж і рух

Створив сцену MainScene, додав об'єкт персонажа та створив перший скрипт PlayerController. Намалював підлогу для рівня за допомогою Tilemap та Rule Tile. Також налаштував керування через Input System (MoveAction) для стрілочок та клавіш WASD.

Найбільше часу пішло на вирішення помилки у Visual Studio, яка видавала вікно міграції проєкту й не хотіла відкривати файл скрипта. Проблему вирішив через Visual Studio Installer, додавши модуль для Unity, та перевибравши редактор у налаштуваннях Unity (External Tools).

Зрозумів, що метод `Update()` викликається щокадру, а множник `Time.deltaTime` перетворює зміщення з «за кадр» на «за секунду». Завдяки цьому персонаж рухається з однаковою швидкістю незалежно від потужності комп'ютера та FPS.
